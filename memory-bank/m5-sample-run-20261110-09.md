1. 字段契约未同步：旧九字段校验不包含requestedCategories；当前脚本明确允许它，且会继续校验品类合法值、去重及category一致性。该输入没有其他未知字段，本地解析通过。正确修复是同步整个代码执行脚本，不删除白名单、不删掉requestedCategories或吞掉解析错误。
