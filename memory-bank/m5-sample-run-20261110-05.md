## 暴露的任务表示与工具边界

自然输入同时要一件上衣和一条裤子，尚未明确锁定某一件188元上衣，也没有明确说要让两件相互搭配。现有提示词允许“多个候选品类都未选定”时category为空，接口却把所有空category都当成顾客没讲品类；search+total也统一要求问预算构成。顾客其实已经说了两类商品，工具只支持一个候选品类或指定主体加一个候选，无法完整处理同时选两个品类。该限制来自本次样例工具设计，不能归咎于顾客不会提问。
