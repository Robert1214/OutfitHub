## 已知限制（非缺陷）

| 项 | 说明 |
| --- | --- |
| 试穿耗时波动 | 48~125 秒，受腾讯云队列影响，超时阈值 3 分钟 |
| 参考图带人体 | MPS 会重画完整人像（出现两个人），已在录入页按分类提示 |
| 搭配卡片无图时 | 显示单品白底图拼的兜底预览，非真实拼合图 |
| Next.js 安全提示 | 16.4.3 版本有已知漏洞，构建/启动时会提示升级，不影响运行 |
