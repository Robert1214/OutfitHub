日期：2026-11-12；2026-11-13按面板核对更新。状态：回答节点已追加比较规则段（草稿保存，未发布）；实际面板与预期不同（编辑面板无输入变量区、单节点运行面板仅sys.query/sys.files），改为临时内联法，见"实际执行方式"；三题未运行，不代表已支持整条比较链路。

## 为什么先单节点

现有正式提取intent没有comparison，解析器拒绝未约定字段；商品工具只支持单品及单个页面主体配下装，S04/S05未入库。若直接在整条预览输入两套比较问题，会同时涉及路由、提取、查询和回答，无法单独观察回答能力。

本轮复用商品分支已有“回答”LLM，先人工提供一份固定比较资料，仅检查有依据的比较和追问。三个问题已在准备过程中讨论过，是功能验证题，不是独立盲测、稳定性测试或用户收益评估。后续仍需设计增量接入及端到端回归。

## 第二步：单节点运行CF01

点击这个回答节点的单节点运行按钮，不点整条Chatflow的预览发送。使用空历史，四个变量按下表填写；如果单节点面板的字段或空值限制不同，停在该面板核对，不转为随意改上游节点。

| 输入变量 | CF01输入 |
| --- | --- |
| 用户输入.product_context | 空字符串；不填S01、数据库商品或假页面 |
| 用户问题/sys.query | 公司不要求正装，我想上班和周末都穿，最近有点凉，也不想太板正。 |
