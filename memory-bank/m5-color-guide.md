# M5 肤色与配色咨询规则

> 规则来源：用户 2026-11-04 定义。
> 适用场景：导购助手收到「白皮 / 黄皮 / 黑皮 / 显白 / 肤色 / 配色」类问题。
> 实现位置：商品分支回答 LLM 的 System Prompt（不放知识库；G05 不会经过政策知识库检索）。
> 参考图：`public/assistant/skin.jpg`、`public/assistant/color.jpg`。

---

## 1. 对话流程

```text
用户提到白皮 / 黄皮 / 黑皮 / 肤色 / 显白
  ↓
是否已经说明冷暖调？
  ├─ 没有 → 先问冷暖，并展示 skin.jpg
  │         （冷调 / 暖调 / 中性调，三选一）
  └─ 有 → 判断肤色明度
            ├─ 明确说较亮 / 偏白 → 基本都能驾驭，可正常推荐
            ├─ 明确说较暗 / 黑 → 情况复杂，转人工，不直接推荐
            └─ 其他 → 按冷暖规则匹配，并展示 color.jpg
```

关键约束：

- **“黑黄皮”按肤色较暗处理**：不直接推荐，询问转人工或先按场合/版型筛选。
- **不要只因为用户说“白皮/黄皮”就直接推荐商品**；先确认冷暖。
- 用户不知道冷暖时，只问一次，并给 `skin.jpg` 参考，不要连续追问。
- 确认冷暖后，先给配色规则，再给商品；商品只能来自工具结果。
- 不承诺“显白/美白/改变肤色”；只做穿搭建议。
- 肤色较暗时转人工，不评价肤色，不强行推荐。

---

## 2. 冷暖配色规则

### 冷皮

- 安全色：冷白、烟灰、藏蓝、冷调墨绿
- 加分色：冰蓝、浅紫、莓红、薄荷绿
- 避雷：深橙、土黄、焦糖色、暖黄

### 暖皮

- 安全色：暖米白、卡其、浅棕、焦糖棕
- 加分色：橘红、姜黄、杏色、暖粉
- 避雷：冷蓝、冷紫、冷调灰

### 中性皮

- 大部分颜色都能驾驭
- 重点看肤色深浅；如果用户明确说较亮，可正常推荐；明确说较暗，转人工

## 3. 可直接粘贴到回答 LLM 的 Prompt

放到商品分支「回答 LLM」的规则区：

```text
【肤色与配色咨询规则】
1. 用户只提到“白皮/黄皮/黑皮”，即使“白皮”听起来像肤色较亮，也先问冷暖，不要直接推荐商品。先问一次：
   “你的手腕血管更偏蓝紫（冷调）、偏绿或橄榄（暖调），还是分不清（中性调）？可以看这张图判断：![肤色判断参考](/assistant/skin.jpg)”
2. 用户回答冷调/暖调/中性调后，按以下规则匹配，并展示配色参考图：
   ![冷暖皮配色参考](/assistant/color.jpg)

   冷皮：
   - 安全色：冷白、烟灰、藏蓝、冷调墨绿
   - 加分色：冰蓝、浅紫、莓红、薄荷绿
   - 避雷：深橙、土黄、焦糖色、暖黄

   暖皮：
   - 安全色：暖米白、卡其、浅棕、焦糖棕
   - 加分色：橘红、姜黄、杏色、暖粉
   - 避雷：冷蓝、冷紫、冷调灰

   中性皮：
   - 大部分颜色都能驾驭，重点看肤色深浅。

3. 只有用户明确说“肤色较亮/亮度较高”，而不是只说“白皮”，才可以直接推荐；此时可以不必强制追问冷暖。
4. 如果用户明确说肤色较暗/黑：不要直接推荐商品；说明“肤色明度较低时建议人工确认”，并询问“需要我帮你转人工，还是先按场合/版型筛选？”；不评价肤色。演示环境不会真的联系客服。
5. 不承诺显白、美白或改变肤色；只做一般穿搭建议。
6. 商品只能来自商品工具结果；如果结果中没有匹配颜色，直接说没有完全匹配，不要编造颜色或商品。
7. 推荐商品最多 4 件；推荐商品必须输出对应商品 ID。
8. 避雷色商品不要主动推荐，也不要输出商品 ID；如果用户明确要求看，说明风险，但不作为推荐。
9. 用户问“店里没有某个颜色，有什么推荐”时，展示 color.jpg 后必须从商品工具结果中推荐 2–4 件接近替代色的商品，并输出商品 ID；不能只给色卡。
```

## 5. 当前商品数据限制

现有 12 件在售商品的色系有限，不能覆盖规则里的所有颜色。例如：

- 冷皮安全色里的藏蓝、冷调墨绿，当前没有完全对应商品
- 暖皮加分色里的橘红、姜黄、杏色，当前没有完全对应商品

因此回答要区分：

- **配色建议**：可以按规则讲颜色
- **可购买商品**：只能从工具结果中选
- 没有对应颜色时，明确说“当前商品里没有完全匹配的色系”，不要硬凑
