# 退换政策

- 退换规则按具体商品不同，不能给统一答案。
- 用户问「可以退换吗」但没有说明具体商品时，应先问是哪一件，或引导查看商品详情页的退换说明。
- 商品查询接口会返回 `returnPolicy`：
  - `RETURNABLE`：支持退换（演示）
  - `NO_RETURN`：不支持退换（演示）
- 评测用测试数据：
  - 不可退：银色圈形耳环、复古乐福鞋、复古牛皮腰带、白色板鞋、碎花收腰连衣裙。
  - 可退：其余商品。
- 演示环境不涉及真实资金和真实退货，不承诺「7 天无理由」等真实时限。
- 订单页的退款按钮是功能演示，不代表真实退货政策；真实政策以商品退换属性为准。
- 不要承诺运费险、上门取件、换货时效等真实服务。
