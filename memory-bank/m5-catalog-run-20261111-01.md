## 已实现

- 共用assistant-requirements结构校验；样例工具通过别名引用，保留已有输入契约，真实查询不加载三件样例数据。
- 原/api/assistant/products增加requirements分支，严格拒绝无效JSON/类型、重复参数和旧q/anchorSampleId等混用。旧请求不带requirements时仍走原查询。
- 独立单品核对ON_SALE且库存>0、品类、全部风格标签、保守关键词、单件预算、已识别排除品类。价格排序在数据库take之前进行，最低符合条件单价超预算时返回差额，不能因截断漏掉便宜商品。
- 不支持任务或无法自动核实的额外条件明确返回空products及状态，不自动丢弃约束。查询候选不作为当前浏览商品。
- 取消聊天代理在无PRODUCTS标记时强行补当前商品/售罄替代品，避免不通过预算的回答仍显示卡片；原前端解析和按ID取卡链路未重建。
- 根据真实DSL生成三个节点的配套草稿；原DSL哈希不变、连接不变；未修改实际Dify、未导入、未发布。
